BIFM settings

Choose which dashboard receives shopping requests. The default is your computer; enter a Cloudflare Worker URL to use the online dashboard from any device.

Online dashboard

Use the root URL of your Worker, for example https://buy-this-for-me.your-name.workers.dev. Do not add /api, a query string, or a password.

When the configured URL is remote, the extension opens the dashboard in a new tab and hands the request over in the URL fragment. Log in on the dashboard when prompted; the request is submitted once after login. The extension never stores the app password.

Local server

Keep http://127.0.0.1:3000 to post directly to the local server started with npm start. Local mode does not ask for a password.
