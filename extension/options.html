BIFM settings

Choose which dashboard receives shopping requests. The online Cloudflare Worker at https://buy-this-for-me.m-vaz-mota.workers.dev is the default. Switch to the local server only when you are developing on this computer.

Online dashboard (default)

The extension uses https://buy-this-for-me.m-vaz-mota.workers.dev unless you save a different URL here. Use the Worker root URL, with no /api path, query string, or password.

When the configured URL is remote, the extension opens the dashboard in a new tab and hands the request over in the URL fragment. Log in on the dashboard when prompted; the request is submitted once after login. The extension never stores the app password.

Local server (optional)

For local development, save http://127.0.0.1:3000 to post directly to the server started with npm start. Local mode is never used automatically: it requires setting the URL explicitly here. Local mode does not ask for a password.
