Choose where shopping requests are sent.

The online Cloudflare Worker at https://buy-this-for-me.m-vaz-mota.workers.dev is the default. Switch to the local server only when you are developing on this computer.

Stored in this browser only and used only to send requests to the online dashboard. Leave empty when using the local server.

Online dashboard (default)

The extension uses https://buy-this-for-me.m-vaz-mota.workers.dev unless you save a different URL here. Use the Worker root URL, with no /api path, query string, or password in the URL.

When the configured URL is remote, the extension sends each request straight to the Worker, with no new tab. Save the app password here first; sending asks you to update it in Settings if it is missing or wrong. The password stays in this browser profile.

Local server (optional)

For local development, save http://127.0.0.1:3000 to post directly to the server started with npm start. Local mode is never used automatically: it requires setting the URL explicitly here. Local mode does not ask for a password.
